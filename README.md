# Abraj International | الأبراج العالمية

Single-page bilingual (Arabic / English) website for Abraj International – General Contracting & Real Estate Investment, Misrata, Libya.

## Files
- `index.html` – the whole site (HTML + CSS + JS)
- (logo is embedded inside `index.html`)

## Publish with GitHub Pages
1. Upload all files to a repository (keep `index.html` at the root).
2. Settings → Pages → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save.
3. For a custom domain (e.g. abrajintl.com): add it under Settings → Pages → Custom domain, then point the domain's DNS to GitHub Pages.
